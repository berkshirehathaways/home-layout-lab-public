# Home Layout Lab

자기 도면과 가구를 등록해 배치를 비교하는 브라우저 기반 2D 도구입니다. 이 저장소에는 실제 집 도면, 개인 가구 목록, 사진, 사용자 계정이나 서버 설정이 들어 있지 않습니다.

## 내 프로젝트로 사용하기

1. GitHub에서 **Fork**를 눌러 내 계정으로 복사합니다.
2. 내 fork의 **Code → Download ZIP**으로 다운로드합니다.
3. 압축을 풀고 standalone.html을 Chrome 또는 Edge에서 엽니다.
4. **도면 올리기**에서 내 PNG·JPG·WebP 도면을 선택합니다. PDF는 먼저 이미지로 저장하세요.
5. **축척 맞추기**를 누르고 길이를 아는 두 점을 선택한 다음 실제 길이를 **cm**로 입력합니다.
6. **가구 추가**로 이름·가로·깊이·사진을 등록하고 도면에 배치합니다. 실제 좌표와 치수는 mm로 저장합니다.
7. A/B/C안을 비교하고 **도면 PNG** 또는 **배치 파일 저장**으로 출력합니다.

별도의 계정·API 키·데이터베이스·Vercel 프로젝트가 필요하지 않습니다. 다른 사용자의 서비스에 연결하지 않습니다. 수정할 때는 index.html과 src/를 변경하고 python3 build.py로 단일 HTML을 다시 만듭니다.

## 내 fork를 웹으로 열기

GitHub 저장소의 **Settings → Pages → Deploy from a branch → main / (root)**를 선택하면 내 계정의 Pages 주소에서 사용할 수 있습니다. 소스는 상대 경로를 사용하므로 저장소 이름과 계정을 바꿔도 동작합니다. 공개할 것은 앱 코드뿐입니다. 도면·사진·프로젝트 JSON을 저장소에 올리지 마세요.

로컬 서버로도 실행할 수 있습니다:

~~~sh
python3 -m http.server 8765 --bind 127.0.0.1
~~~

프로젝트 폴더에서 위 명령을 실행한 뒤, 브라우저 주소창에 아래 주소를 입력하거나 링크를 클릭하세요.

[http://127.0.0.1:8765/](http://127.0.0.1:8765/)

서버를 종료하려면 실행 중인 터미널에서 Control+C를 누르세요.

## 저장과 개인정보

도면 업로드는 외부 전송이 아닌 **이 브라우저에서 파일 읽기**입니다. 편집한 도면·사진·가구·배치는 localStorage에 저장하며 서버로 전송하지 않습니다. 다른 기기나 다른 사람이 자동으로 읽지 못하고 공동 편집도 하지 않습니다. GitHub Pages에서 같은 `username.github.io` 아래의 다른 페이지는 브라우저 보안 정책상 같은 origin의 localStorage에 접근할 수 있습니다. 민감한 도면은 로컬 서버, 별도 브라우저 프로필, 또는 서로 다른 도메인을 사용하고, 저장소에는 JSON·PNG를 올리지 마세요.

**배치 파일 저장**으로 받은 JSON은 도면 이미지·사진·A/B/C 배치를 포함합니다. 브라우저 데이터 삭제, 다른 기기 이동, 저장 용량 부족에 대비해 이 파일을 따로 보관하세요. PNG는 그림이므로 편집 상태를 복원할 수 없습니다. file:// 저장은 브라우저에 따라 다를 수 있어 불안정하면 로컬 서버를 사용하세요.

빈 저장소를 fork하면 빈 프로젝트로 시작합니다. 소스에 사용자 데이터를 넣지 않는 한 fork·앱 업데이트로 도면이 공개되지 않습니다. 내보낸 JSON·PNG를 누구에게 전달할지는 사용자가 결정합니다.

## 포함된 도구와 범위

- 도면 업로드, 축척 보정, 거리 측정, 전체 지도 이동·확대
- 가구/사진/치수 등록, 배치·회전·잠금·복제, A/B/C, undo/redo
- 수동 벽·고정 설비·문·방 경계 입력과 입력 기준 충돌 검사
- 가구 이름·치수와 연결선을 포함하는 A4 PNG, 전체 프로젝트 JSON 백업

가구는 직사각형으로 근사합니다. 이미지에서 벽이나 가구를 자동 인식하지 않습니다. 축척은 단일 비율이며 원근 있는 사진에는 정확히 맞지 않습니다. 미등록 공간·높이·반입 동선은 검사하지 않습니다. 경고가 없다고 실제 설치가 가능한 것은 아닙니다. 편집은 데스크톱 브라우저 사용을 권장합니다.

## 검증

node --test tests/*.cjs

python3 tests/test_public_browser.py
~~~

마지막 브라우저 검증은 별도 개발 환경의 Playwright와 Pillow가 필요합니다. 앱 실행에는 개발 의존성이 필요하지 않습니다. 실행 결과는 TEST_REPORT.md에 기록합니다.
